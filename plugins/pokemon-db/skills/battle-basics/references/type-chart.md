# タイプ相性表

攻撃側タイプ（行）× 防御側タイプ（列）の倍率。

- 空白 = ×1（等倍）
- **2** = ×2（こうかはばつぐん）
- ½ = ×0.5（こうかはいまひとつ）
- ✕ = ×0（こうかがない）
