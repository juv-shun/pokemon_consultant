ポケモンチャンピオンズのダメージ計算を行う。

ユーザーの入力: $ARGUMENTS

## 手順

### 1. 入力情報の整理

ユーザーの入力から以下を特定する:
- 攻撃側ポケモン（名前、性格、努力値配分）
- 使用する技
- 防御側ポケモン（名前、性格、努力値配分）
- その他条件（天候、壁、持ち物、特性、やけど、急所、ダブルバトルの全体技かどうか等）

**性格・努力値が指定されていない場合**、ユーザーに確認せず `champions-trend` スキルを使って当該ポケモンの採用実績を参照し、代表的な性格・努力値を使用する。使用した値は計算結果とともに「（champions-trend 参照）」と明示する。`champions-trend` に詳細データがない場合のみユーザーに確認する。その他の不明情報（天候・壁・持ち物等）はユーザーに確認する。

### 2. DB参照

Supabase MCPを使って必要なデータを取得する。

```sql
-- 攻撃側ポケモンの種族値・タイプ
SELECT name_ja, type_primary, type_secondary, base_atk, base_spa, base_spe
FROM champions.pokemon WHERE name_ja = '攻撃ポケモン名';

-- 防御側ポケモンの種族値・タイプ
SELECT name_ja, type_primary, type_secondary, base_hp, base_def, base_spd
FROM champions.pokemon WHERE name_ja = '防御ポケモン名';

-- 技の情報
SELECT name_ja, type_name, damage_class, power, accuracy
FROM champions.moves WHERE name_ja = '技名';
```

### 3. ステータス実数値の算出

`/calc-stats` スキルを使って攻撃側・防御側の実数値を計算する。

- 攻撃側のこうげき or とくこう（技の damage_class に応じて選択）
- 防御側のぼうぎょ or とくぼう
- 防御側のHP（確定数計算に必要）

### 4. 補正の判定

DB情報から以下を判定する:
- **タイプ一致（STAB）**: 技のtype_nameが攻撃ポケモンのtype_primary/type_secondaryと一致するか
- **タイプ相性**: 技のtype_nameと防御ポケモンのタイプから相性倍率を算出
- **effect_text の参照**: `is_spread=FALSE` かつ `target='single'` であっても、effect_textに条件付き全体化の記述がある場合はその条件を確認し、成立していれば全体技として扱う

タイプ相性表（抜粋、全18タイプの相性はポケモン公式準拠）:
- 2倍: ほのお→くさ、みず→ほのお、でんき→みず 等
- 0.5倍: ほのお→みず、くさ→ほのお 等
- 0倍: ノーマル→ゴースト、でんき→じめん 等
- 2タイプの場合は倍率を掛け合わせる（4倍、0.25倍もあり得る）

#### 特性・持ち物による補正

ダメージ計算前に、攻撃側の特性と持ち物がダメージに影響するか必ず確認する。スクリプトの `--item` オプションにないものは `--other {倍率}` で指定する。複数の補正が重なる場合は `--other` の倍率を掛け合わせる。

**主な特性補正の例:**

| 特性 | 補正 | 適用条件 |
|------|------|----------|
| てきおうりょく | タイプ一致が×1.5→**×2.0** | タイプ一致技を使うとき。`--stab` の代わりに `--other 2.0` を使う |
| すてみ | ×1.2 | 反動技を使うとき |
| てつのこぶし | ×1.2 | パンチ技を使うとき |
| がんじょうあご | ×1.5 | かみつき技を使うとき |

**持ち物補正（`--item type-boost`）:**

ポケモンチャンピオンズの持ち物によるダメージ補正はすべてタイプ別×1.2。該当タイプの技を使う場合に `--item type-boost` を追加する。

| 持ち物例 | 補正 | 対象タイプ |
|--------|------|-----------|
| しんぴのしずく | ×1.2 | みず |
| もくたん | ×1.2 | ほのお |
| じしゃく | ×1.2 | でんき |
| くろおび | ×1.2 | かくとう |
| まがったスプーン | ×1.2 | エスパー |
| のろいのおふだ | ×1.2 | ゴースト |
| りゅうのキバ | ×1.2 | ドラゴン |
| （その他タイプ別アイテムも同様） | ×1.2 | 各タイプ |

#### 条件付き全体技の代表例

**ワイドフォース**（威力80 / エスパー / 特殊）  
effect_text:「場の状態が『サイコフィールド』で、自分が『ひこう』タイプや特性『ふゆう』などではなく地面にいる時、威力が1.5倍になり(フィールドの1.3倍の効果もさらに加わる)、また相手全体を攻撃する(その時ダブルバトルではダメージは0.75倍)。」

条件成立時（サイコフィールド＋使用者が地面にいる）の補正:
- 威力: 80 × 1.5 = **120**
- フィールド補正: × 1.3
- ダブルバトルで全体技扱い: × 0.75
- → `--power 120 --other 1.3 --spread` で計算する

条件不成立時は通常の単体技として計算する（`--power 80`、spread なし）。

### 5. ダメージ計算

`calc_damage.py` を使ってダメージを算出する。

```bash
python .claude/skills/calc-damage/scripts/calc_damage.py \
  --power {威力} \
  --attack {攻撃実数値} \
  --defense {防御実数値} \
  [--stab] \
  [--effectiveness {相性倍率}] \
  [--critical] \
  [--burn] \
  [--weather {sun/rain/none}] \
  [--weather-boosted] \
  [--weather-weakened] \
  [--wall {single/double/none}] \
  [--spread] \
  [--item type-boost] \
  [--other {倍率}]
```

### 6. ステータスランク補正の適用

バトル中にランク変化がある場合、実数値にランク倍率を掛けてから計算する。

**攻撃・防御・特攻・特防・素早さのランク倍率**（正のとき `(2+n)/2`、負のとき `2/(2+|n|)`）:

| ランク | 倍率 | ランク | 倍率 |
|--------|------|--------|------|
| +1 | 3/2 (×1.5) | -1 | 2/3 (×0.67) |
| +2 | 4/2 (×2.0) | -2 | 2/4 (×0.5) |
| +3 | 5/2 (×2.5) | -3 | 2/5 (×0.4) |
| +4 | 6/2 (×3.0) | -4 | 2/6 (×0.33) |
| +5 | 7/2 (×3.5) | -5 | 2/7 (×0.29) |
| +6 | 8/2 (×4.0) | -6 | 2/8 (×0.25) |

### 7. 結果の解釈と回答

以下を含めて回答する:
- **ダメージ範囲**: 最小〜最大ダメージ
- **確定数**: 防御側HPに対して何発で倒せるか（乱数最小・最大それぞれ）
  - 確定1発 = 最小ダメージ ≥ HP
  - 乱数1発 = 最小ダメージ < HP ≤ 最大ダメージ
  - 確定2発 = 最小ダメージ×2 ≥ HP
  - 等
- **割合**: HP に対するダメージの割合（%）
- **適用された補正の一覧**

## 参考: ダメージ計算式の詳細

> **注意**: 本家ポケモンのダメージ計算式をベースとしている。ポケモンチャンピオンズ固有の差異がある可能性があり、判明次第更新する。

基本ダメージは以下の計算式で算出される（レベル=50 固定）。

```
基本ダメージ = floor(floor(22 × 技の威力 × A ÷ D) ÷ 50) + 2
最終ダメージ = floor(基本ダメージ × 各種補正 × 乱数)
```

- **A**: 攻撃側のステータス実数値（物理技→こうげき、特殊技→とくこう）
- **D**: 防御側のステータス実数値（物理技→ぼうぎょ、特殊技→とくぼう）
- **22**: レベル補正値（= floor(50×2÷5+2)）
- **乱数**: 0.85〜1.00 の16段階（同条件でもダメージにばらつきが出る）

### 各種補正一覧

| 補正 | 倍率 | 条件 |
|------|------|------|
| タイプ一致（STAB） | ×1.5 | 技のタイプと攻撃ポケモンのタイプが一致 |
| タイプ相性 | ×0/0.25/0.5/1/2/4 | 技タイプと防御ポケモンのタイプの相性 |
| 急所 | ×1.5 | 急所に当たった場合 |
| やけど | ×0.5 | 攻撃側がやけど状態で物理技を使用 |
| 壁（シングル） | ×0.5 | リフレクター/ひかりのかべ（シングルバトル） |
| 壁（ダブル） | ×2/3 | リフレクター/ひかりのかべ（ダブルバトル） |
| 全体技（ダブル） | ×0.75 | ダブルバトルで2体以上を対象とする技 |
| 天候（強化） | ×1.5 | 晴れ+ほのお技、雨+みず技 |
| 天候（弱化） | ×0.5 | 晴れ+みず技、雨+ほのお技 |
| タイプ別強化アイテム | ×1.2 | しんぴのしずく・もくたん・じしゃく等、対応タイプの技を使うとき |
| 特性 | 各種 | 特性による補正（種類が多いため個別参照） |

### 命中率・回避率のランク倍率

倍率 = 正のとき `(3+n)/3`、負のとき `3/(3+|n|)`

| ランク | 倍率 | ランク | 倍率 |
|--------|------|--------|------|
| +1 | 4/3 (×1.33) | -1 | 3/4 (×0.75) |
| +2 | 5/3 (×1.67) | -2 | 3/5 (×0.6) |
| +3 | 6/3 (×2.0) | -3 | 3/6 (×0.5) |
| +4 | 7/3 (×2.33) | -4 | 3/7 (×0.43) |
| +5 | 8/3 (×2.67) | -5 | 3/8 (×0.38) |
| +6 | 9/3 (×3.0) | -6 | 3/9 (×0.33) |

### 命中判定

```
実際の命中率 = 技の命中率 × 自分の命中ランク倍率 ÷ 相手の回避ランク倍率
```

例: 命中率100の技を、命中ランク0の状態で、回避ランク+1の相手に使う場合、`100 × 1.0 ÷ 1.33 ≒ 75%` の命中率となる。
