ポケモンチャンピオンズのステータス実数値を計算する。

ユーザーの入力: $ARGUMENTS

## 手順

### 1. 入力情報の整理

ユーザーの入力から以下を特定する:
- ポケモン名
- 性格
- 各ステータスの努力値配分

**性格・努力値が指定されていない場合**、ユーザーに確認せず `battle-data` スキルを使って当該ポケモンの採用実績を参照し、代表的な性格・努力値を使用する。使用した値は計算結果とともに「（battle-data 参照）」と明示する。`battle-data` に詳細データがない場合のみユーザーに確認する。

### 2. DB参照

Supabase MCPを使って種族値を取得する。

```sql
SELECT name_ja, base_hp, base_atk, base_def, base_spa, base_spd, base_spe
FROM champions.pokemon WHERE name_ja = 'ポケモン名';
```

### 3. 計算式

以下の計算式（ポケモンチャンピオンズ独自）で実数値を算出する。

- **最大HP**: `種族値 + 努力値 + 75`
- **こうげき・ぼうぎょ・とくこう・とくぼう・すばやさ**: `floor(性格補正 × (種族値 + 努力値 + 20))`

### 4. 性格補正

性格によってHP以外のステータスについて補正がかかる。

| 性格 | 上がる(×1.1) | 下がる(×0.9) |
|------|-------------|-------------|
| さみしがり | 攻撃 | 防御 |
| いじっぱり | 攻撃 | 特攻 |
| やんちゃ | 攻撃 | 特防 |
| ゆうかん | 攻撃 | 素早さ |
| ずぶとい | 防御 | 攻撃 |
| わんぱく | 防御 | 特攻 |
| のうてんき | 防御 | 特防 |
| のんき | 防御 | 素早さ |
| ひかえめ | 特攻 | 攻撃 |
| おっとり | 特攻 | 防御 |
| うっかりや | 特攻 | 特防 |
| れいせい | 特攻 | 素早さ |
| おだやか | 特防 | 攻撃 |
| おとなしい | 特防 | 防御 |
| しんちょう | 特防 | 特攻 |
| なまいき | 特防 | 素早さ |
| おくびょう | 素早さ | 攻撃 |
| せっかち | 素早さ | 防御 |
| ようき | 素早さ | 特攻 |
| むじゃき | 素早さ | 特防 |
| てれや | - | - |
| がんばりや | - | - |
| すなお | - | - |
| きまぐれ | - | - |
| まじめ | - | - |

補正なし（±0）の性格は `--nature neutral`（または省略）で計算する。

### 5. スクリプトで計算

`calc_stats.py` を使って実数値を算出する。

```bash
python .Codex/skills/calc-stats/scripts/calc_stats.py --base 種族値 --ev 努力値                  # HP以外(補正なし)
python .Codex/skills/calc-stats/scripts/calc_stats.py --base 種族値 --ev 努力値 --nature up      # 性格補正↑(×1.1)
python .Codex/skills/calc-stats/scripts/calc_stats.py --base 種族値 --ev 努力値 --nature down    # 性格補正↓(×0.9)
python .Codex/skills/calc-stats/scripts/calc_stats.py --base 種族値 --ev 努力値 --hp             # HP
```

### 6. 結果の回答

算出した各ステータスの実数値を一覧で示す。

## 参考: 努力値ルール

- 合計66まで振ることができる
- 1つのステータスに最大32まで振ることができる
