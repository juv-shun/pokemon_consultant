# my-pokemon

自分の育成済みポケモンを保存するフォルダ。

## ファイル命名規則

- 基本: `ポケモン名.yaml`（例: `ガブリアス.yaml`）
- 型が複数ある場合: `ポケモン名_型名.yaml`（例: `ガブリアス_スカーフ.yaml`、`ガブリアス_珠.yaml`）

型名ありのファイルは、ユーザーが「スカーフガブリアス」「珠ガブリアス」などと指定したときに参照される。  
型名なしのファイルは、単に「ガブリアス」と指定したときのデフォルト個体として参照される。

## ファイルフォーマット

```yaml
name: ポケモン名
calc_as: メガポケモン名  # 省略可。ダメ計・ステ計で使う種族値のポケモン名（メガ進化・フォルム変化時に指定）
also_calc_base: true    # 省略可。true にすると name の種族値でも追加で計算する
nature: ようき
ability: さめはだ
item: こだわりスカーフ
evs:
  H: 0
  A: 32
  B: 0
  C: 0
  D: 2
  S: 32
notes: 備考（省略可）
```

- `calc_as` は省略可能。指定した場合、ダメ計・ステ計でその種族値を使う
- `also_calc_base` は省略可能。`calc_as` と併用し `true` にすると、メガ前（`name`）とメガ後（`calc_as`）の両方で計算する
- `evs` は省略したステータスを 0 扱い
- `notes` は省略可能

## 参照優先度

`calc-damage` / `calc-stats` などのスキルで性格・努力値を指定しなかった場合、以下の優先度で参照される。

1. `my-pokemon/ポケモン名.yaml`（自分の育成個体）
2. `battle-data` スキル（環境の代表的育成）
3. ユーザーへの確認
